## 🎓 安全原理说明

### 为什么需要域名白名单？
**问题**: 没有限制的网络请求可能导致：
- 数据泄露到未授权服务器
- 恶意服务器注入攻击
- 隐私数据被拦截

**解决**: 只允许访问已知的安全域名

---

### 为什么要禁用 WebView 跨域访问？
**问题**: `allowFileAccessFromFileURLs = true` 允许：
- JavaScript 读取应用私有文件
- 数据库文件泄露
- SharedPreferences 泄露

**解决**: 禁用跨域访问，限制 WebView 只能加载本地 assets

---

### 为什么需要防御 ZIP 炸弹？
**问题**: ZIP 炸弹是压缩比极高的恶意文件：
- 1 KB 压缩包可能解压为 1 GB
- 导致应用崩溃或设备卡死

**解决**: 监控解压后的实际大小，超过预期则中断

---

### 为什么要验证文件名？
**问题**: 恶意文件名可能包含路径穿越：
- `../../sdcard/malicious.db`
- `../../../data/data/com.other.app/databases/steal.db`

**解决**: 清理文件名，只保留安全字符
